#  Sales Analytics Portfolio

Este repositório reúne projetos de análise de vendas desenvolvidos com Excel e Power Query.

Os projetos incluem processos de ETL (Extração, Transformação e Carregamento de Dados), limpeza e tratamento de dados, criação de KPIs e desenvolvimento de dashboards para apoio à tomada de decisão.

## Projetos

### 1. Dashboard de Vendas
Análise de desempenho comercial através de indicadores e visualizações interativas.

### 2. Superstore Data Analysis
Projeto completo de ETL e análise de dados utilizando o dataset Superstore, incluindo limpeza de dados, cálculo de métricas de negócio e construção de dashboard executivo.
